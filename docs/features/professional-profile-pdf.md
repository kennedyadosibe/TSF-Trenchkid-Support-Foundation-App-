# Professional Profile PDF

## Summary

Created a polished TSF professional profile and partnership brief as a PDF for sharing with donors, partners, institutions, and professional stakeholders. Updated the July 2026 version so impact numbers are presented as expected targets and program goals, not completed support.

## File

`output/pdf/tsf-professional-profile.pdf`

## Content

The PDF covers:

- TSF executive profile
- Mission, vision, and values
- Core programs
- Impact model and expected targets
- Operational readiness and accountability
- Partnership and funding opportunities
- Contact and follow-up information

## Verification

The PDF was rendered to PNG pages with Poppler and visually checked for layout, readability, clipping, page numbering, and section consistency.
